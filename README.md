## 🛠️ Getting Started

### Prerequisites

To run the local analysis environments and migration scripts, ensure you have the following installed:

* Python 3.10+
* MySQL Server 8.0+
* Microsoft Power BI Desktop (for interacting with `.pbix` reports)

### Local Technical Setup

1. **Clone the Repository:**
```bash
git clone https://github.com/your-username/data-portfolio.git
cd data-portfolio


```

2. **Environment Configuration:**
   Initialize a Python virtual environment and install the required data manipulation libraries:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   pip install -r requirements.txt

```

3. **Database Initialization:**
If deploying the localized analytics workspace, execute the structural scripts against your local database server instance:
```bash
mysql -u root -p < database-scripts/initialize_server.sql

```
